- This project was built in Selenium-Java using IntelliJ IDE. JDK-20
- The purpose of this project is to automate the manual steps for testing the Login and Add item to Cart functions.
- Test URL: https://automationexercise.com
- The test runs parallel in Chrome-Firefox-Edge browsers
- The file "testng.xml" is used for running entire project.
- After successfully running this project, a file "CasesFailed-Screenshots" will be generated holding
screenshots of failed cases.
